# Method — SKU hierarchy

Five levels: total > state > store > dept > SKU. Global GBM base, direct 28-step. MinT-shrink: W = λ diag + (1-λ) cov. Coherence error after MinT should be ~0; base SKU-sum vs total is the incoherence you show.

WRMSSE: RMSSE per node, revenue-weighted, averaged across levels. If MinT does not beat base at total, the covariance is junk — do not ship.
