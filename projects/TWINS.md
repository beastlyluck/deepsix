# Six twins, six stacks

Each twin is a different industry and a different runtime on purpose. If you
find yourself adding FastAPI to ForgeX or PyTorch to TerraTwin, stop.

| Twin | Product | Dashboard | Docs |
|---|---|---|---|
| AeroTwin | TorchScript + C++ 400 Hz loop, gRPC | Raw WebGL swarm + terminal | S2R gap, CAD chunking, proto |
| GridPulse | HiGHS dispatch against a PINN rating | SVG node graph + alert drawer | PINN loss, GNN hops, Avro |
| BioSync | ONNX RK4 on-device | Streamlit + static JS replica | DP check, ODE vs ESN matrix |
| OceanicOS | Hungarian assignment matrix | Canvas port + WS replay | Layout graph, ST-GNN, API |
| ForgeX | JSON logit + HOLD interlock | Three.js arm + FFT | Late fusion, STFT bands, FSM |
| TerraTwin | FQI loop + facility.toml | SVG rack grid + what-if | Reward, sensors, k8s |

Run any one with `python main.py` then open `site/index.html` and `docs/index.html`.
