# Method — Fraud ring

Accounts linked on shared device or address. Graph features: degree, component size, triangles, shared-device count. Logit twice: tabular vs tabular+graph. Score is PR-AUC.

Packs: components with ≥2 accounts above 0.5. Sentence lists shared entities, velocity, age. False family = pack with zero true fraud. Review-time math is printed with the assumptions.
